This project will show you how you can create shell scripts using JavaScript and Java.

Using your own built JavaScript engine based on GraalVM and Java.

You can run a JavaScript Shell Script after downloading jss, install Java, 
open a terminal under jss/ScriptSamples and run:

./jss.ksh test.jss

On Windows, open a Terminal window and run example:

.\jss.bat .\test.jss

Note. To run the scripts you can use other JVM than GrallVM, like: https://adoptium.net/ JVM
