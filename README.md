# jss
JavaScript Shell Scripting

Last project update: April 20 2026

Project creation Date: April 11 2025

This project will show you how you can create shell scripts using JavaScript and Java.

Using your own built JavScript engine based on GraalVM and Java.

You can run a JavaScript Shell Script after downloading jss, install Java, 
open a terminal under jss/ScriptSamples and run:

./jss.sh test.jss


# How to compile the sources:

- Install Java from graalvm(https://www.graalvm.org/) community(https://github.com/graalvm/graalvm-ce-builds/releases), last jss version I used : Java GraalVM Community LTS 21
- Install Maven(https://maven.apache.org/download.cgi), last jss version, I used : Apache Maven 3.9.12

Happily compile with: mvn clean package

Check your jar files under target directory.
